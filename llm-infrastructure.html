Artifact 3 — LLM Infrastructure Cost Dashboard

This visual artifact explains how a large language model is trained and why training requires major resources across data, compute, energy, and time.

Title

LLM Infrastructure Cost Dashboard. This portfolio artifact visualizes how large language models move from raw training data to deployed systems, using Meta Llama 2 as the main model example.

Introduction

Large language models are often discussed as software products, but the training process also depends on large-scale infrastructure. This artifact makes that hidden infrastructure easier to understand by connecting the training pipeline to four cost categories: data, compute, energy, and time.

Description

The dashboard shows a linear LLM training flow: data collection, cleaning and filtering, tokenization, pretraining, alignment, evaluation, and deployment. It also compares named model examples using sourced figures. Llama 2 is the main case study, while GPT-4 and Gemini Ultra are used as frontier-cost comparison points.

Objective

The objective is to explain LLM training to a non-technical audience without hiding the operational trade-offs. The artifact emphasizes that model capability is shaped not only by algorithm design, but also by the amount of data, compute, energy, time, and capital available.

Process

1. Model Selection

I selected Meta Llama 2 because its model card reports useful public figures, including training tokens, GPU-hours, emissions, and training dates.

2. Classification

I grouped the evidence into the required cost categories: data, compute, energy, and time. This made the visual easier to scan than a source-by-source list.

3. Design Revision

The final design uses one flow, four cost cards, and a short comparison note. This keeps the artifact readable while still showing the relationship between training steps and real infrastructure costs.

Tools & Technologies

Tools and sources used include infographic design, HTML/CSS, GitHub Pages, Meta Llama 2 documentation, Stanford AI Index cost estimates, and OpenAI technical documentation. The page is designed as a shareable portfolio deliverable rather than a standalone written report.

Value Proposition

For faculty, students, and business stakeholders evaluating generative AI, this artifact explains why frontier LLM development is expensive and difficult to reproduce. Its unique contribution is the combination of a training-process map with cost evidence from named models, making the infrastructure trade-off visible in one view.
