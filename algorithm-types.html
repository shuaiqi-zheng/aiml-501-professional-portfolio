Artifact Overview

Title: Algorithm Types Visual Framework

Introduction: Algorithms form the foundation of machine learning systems. They determine how models learn from data, identify patterns, make predictions, group similar cases, and generate new content. This artifact presents a visual framework for understanding major algorithm families across tabular data, computer vision, natural language processing, and generative AI.

Description: This portfolio artifact is an infographic-style reference that classifies ten machine learning algorithms by learning type, application domain, example use case, and core operating logic. It is designed to help learners and professionals quickly understand how different algorithms relate to each other and where they are commonly applied.

Objective: To clearly identify and categorize key machine learning algorithms, explain their primary application domains, and communicate their practical significance in real-world AI and analytics settings.

Process: I selected a balanced group of algorithms across supervised learning, unsupervised learning, computer vision, NLP, and generative AI. I then organized them into a visual framework that groups algorithms by application domain while also showing their learning style and use cases.

Tools & Technologies: HTML, CSS, GitHub Pages, course readings, educational videos, academic references, and generative AI assistance for organization and language refinement.

Value Proposition: This artifact demonstrates my ability to synthesize complex AI/ML concepts into a clear professional resource that can support learning, technical communication, and applied model selection.

Unique Value: My framework connects algorithm concepts to practical business and analytics contexts, including fraud detection, customer segmentation, image recognition, language modeling, and generative content creation.

Relevance: Understanding algorithm types is essential for selecting the right modeling approach for a problem. This is especially relevant in financial services, risk analytics, and responsible AI, where model choice affects performance, interpretability, fairness, and operational impact.

Machine Learning Algorithm Map

This framework classifies ten common algorithms across four major application domains: tabular data, computer vision, natural language processing, and generative AI. Each card shows the learning type, common domain, practical use case, and a brief explanation of how the algorithm works.

Supervised Unsupervised Self-Supervised / Generative Tabular Data Computer Vision NLP Generative AI

Tabular Data

Decision Tree

Supervised Tabular

Use Case: Loan approval, fraud rules, customer churn classification.

How It Works: Splits data into branches using yes/no questions until it reaches a prediction.

Random Forest

Supervised Tabular

Use Case: Fraud detection, credit risk scoring, account abuse detection.

How It Works: Builds many decision trees and combines their outputs to improve stability and reduce overfitting.

Gradient Boosting

Supervised Tabular

Use Case: Risk prediction, transaction scoring, marketing response modeling.

How It Works: Builds models sequentially, with each new model correcting errors from prior models.

Pattern Discovery

K-Means Clustering

Unsupervised Tabular

Use Case: Customer segmentation, behavioral grouping, anomaly exploration.

How It Works: Groups observations into K clusters based on similarity and distance from cluster centers.

Principal Component Analysis

Unsupervised Tabular Vision

Use Case: Dimensionality reduction, feature compression, exploratory analysis.

How It Works: Transforms many correlated variables into fewer components that preserve the most variation.

Computer Vision

Convolutional Neural Network

Supervised Vision

Use Case: Image classification, object detection, medical image analysis.

How It Works: Uses convolutional filters to detect visual patterns such as edges, shapes, and objects.

Generative Adversarial Network

Generative Vision GenAI

Use Case: Synthetic image generation, image enhancement, creative media.

How It Works: Trains two networks against each other: a generator creates outputs and a discriminator evaluates whether they look real.

NLP and Generative AI

BERT

Self-Supervised NLP

Use Case: Sentiment analysis, search ranking, document classification.

How It Works: Learns language representations by reading text bidirectionally and understanding context around words.

GPT / Large Language Model

Self-Supervised NLP GenAI

Use Case: Text generation, summarization, code assistance, customer support automation.

How It Works: Predicts the next token in a sequence and uses transformer attention to generate context-aware language.

Diffusion Model

Generative Vision GenAI

Use Case: Image generation, design prototypes, visual content creation.

How It Works: Learns to remove noise step by step, gradually transforming random noise into a realistic image or other output.

Prediction

Decision Trees, Random Forests, Gradient Boosting, and CNNs are often used when labeled outcomes are available and the goal is to predict a class or value.

Pattern Discovery

K-Means and PCA help discover structure when labels are limited or unavailable, making them useful for segmentation and data exploration.

Representation Learning

BERT, GPT, CNNs, and diffusion models learn internal representations from large-scale data, allowing them to handle images, language, and generated content.

Content Generation

GANs, diffusion models, and GPT-style models move beyond prediction by creating new images, text, and other outputs.

Classification Process

I classified the algorithms using two primary lenses. First, I sorted each algorithm by learning style: supervised, unsupervised, or self-supervised/generative. Supervised algorithms learn from labeled examples, while unsupervised algorithms identify structure without explicit labels. For modern generative AI systems, I used a self-supervised/generative label because models such as GPT and diffusion models often learn from large-scale data without traditional manually labeled target variables.

Second, I grouped the algorithms by application domain. Tabular algorithms are commonly used for structured business data, such as customer records, transactions, or risk scores. Computer vision algorithms process images and visual patterns. NLP algorithms process language, meaning, and text relationships. Generative AI algorithms create new content, such as text or images. Some algorithms appear in more than one domain because modern AI systems often combine techniques across tasks.
