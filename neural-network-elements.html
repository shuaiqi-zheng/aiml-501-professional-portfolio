Feedforward Neural Network Diagram

A feedforward neural network moves information in one direction: from input features, through hidden layers, to an output prediction. The model learns by adjusting the weights between neurons.

Forward flow: input features → weighted neuron calculations → activation functions → hidden representations → output prediction.

Required Neural Network Elements

Layers

Layers

Layers organize the flow of information. The input layer receives data, hidden layers learn patterns, and the output layer produces the final prediction.

Neurons

Neurons

Neurons are processing units. Each neuron combines inputs, weights, and bias, then passes the result through an activation function.

Weights

Weights

Weights control how strongly one neuron influences another. During training, the network adjusts weights to reduce error.

Activation Functions

Activation Functions

Activation functions allow the network to learn nonlinear patterns. Examples include ReLU for hidden layers and sigmoid or softmax for outputs.

Loss Functions

Loss Functions

A loss function measures the difference between the model’s prediction and the correct answer. It defines what the model is trying to minimize.

Optimization Algorithms

Optimization Algorithms

Optimization algorithms update weights to reduce loss. Gradient descent and Adam are common approaches for improving model performance.

How the Network Learns

A neural network does not learn from one pass through the data. It improves through repeated cycles of prediction, loss measurement, backpropagation, and optimization.

1. Input

Features enter the network, such as pixels, transaction variables, or text embeddings.

2. Forward Pass

Inputs move through weighted connections and activation functions to produce a prediction.

3. Loss

The prediction is compared with the true label to calculate error.

4. Backpropagation

The model estimates how much each weight contributed to the error.

5. Optimization

The optimizer updates weights to reduce future loss.

Architecture Choices and Use Cases

Architecture Choice What It Controls When It Helps Example Use Case
Depth Number of hidden layers. More depth helps the model learn layered, complex patterns but can increase training time and overfitting risk. Image classification where early layers learn edges and deeper layers learn shapes or objects.
Width Number of neurons in each layer. More width gives the network more capacity to learn patterns, but too much width may memorize noise. Tabular prediction with many interacting variables, such as fraud risk or customer churn.
Activation Function How each neuron transforms its weighted input. ReLU is useful in hidden layers because it trains efficiently; sigmoid or softmax is useful for probabilities. Softmax output for multi-class digit classification.
Loss Function The error measure the model tries to minimize. Different tasks need different losses: cross-entropy for classification and mean squared error for regression. Cross-entropy for classifying MNIST digits from 0 to 9.
Optimizer How weights are updated during training. Adam often trains efficiently; gradient descent is easier to explain and useful for learning fundamentals. Training a simple feedforward model in Neural Network Playground.

Worked Example: Classifying MNIST Digits

In a digit classification task, the neural network receives an image of a handwritten digit and predicts which number it represents. A simple feedforward network can classify the image by converting pixel values into input features, passing them through hidden layers, and producing class probabilities for digits 0 through 9.

Neural Network Playground Insights

Neural Network Playground showed how model structure and data quality affect training. Changing the number of layers, neurons, features, and noise level changed how quickly the model learned and how complex the decision boundary became.

Noise

Higher noise made the model harder to train because the classes were less clearly separated.

Depth and Width

More layers and neurons increased flexibility, but also increased training complexity and overfitting risk.

Feature Selection

Better input features helped the network learn cleaner decision boundaries with less unnecessary complexity.

Summary

Visualizing neural networks makes the learning process easier to understand. A network is not just a set of boxes; it is a system where inputs move through weighted connections, neurons apply activation functions, predictions are compared against correct answers, and optimizers update weights to reduce loss.

The key insight from this exercise is that neural network performance depends on both data quality and architecture choices. Depth, width, activation functions, loss functions, and optimization algorithms all influence how well the model learns. This artifact helped me connect neural network structure to practical modeling decisions used in computer vision, NLP, generative AI, and predictive analytics.
