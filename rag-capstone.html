Introduction

This capstone artifact applies retrieval-augmented generation (RAG) to an academic policy-support problem. The goal was not to build a general chatbot, but to design a responsible assistant that retrieves handbook evidence before answering and avoids unsupported policy conclusions.

Try the IWU Faculty Handbook Guide See Validation & Guardrails

Description

The project is an IWU Faculty Handbook Guide Custom GPT. It supports routine questions from faculty, department chairs, and academic affairs users about topics such as grading, AI use, attendance, student data, appeals, and academic procedure. The assistant follows a grounded answer pattern: direct answer, cited handbook section, limitation or scope note, and escalation when the source does not support a confident answer.

Business Problem → RAG Response Designed for policy questions where speed alone is not enough
🔎Fragmented lookup

Handbook answers can be spread across grading, AI use, appeals, FERPA, and academic-procedure sections.

⚖️Interpretation risk

Different readers may summarize the same policy differently without a shared source trail.

📌Traceable answer

The assistant retrieves the section first, then gives a concise answer with citation and scope limits.

Important scope limit: The system uses a teaching-version handbook extract for the AIML-501 capstone. It is designed for classroom demonstration and pilot evaluation, not as a replacement for official IWU policy interpretation.

Objective

The objective was to reduce repeated policy lookup work while improving consistency, transparency, and accountability. Instead of relying on memory or unsupported GPT output, the assistant uses handbook retrieval, citation traceability, and escalation rules so users can verify the policy source before acting.

Primary Users

Faculty members, department chairs, and Academic Affairs staff needing quick, consistent handbook-policy answers.

Typical Questions

Graduate passing grade, approved AI use, attendance expectations, student-data systems, and appeal steps.

Expected Output

Direct answer → cited handbook section → limitation note → escalation if evidence is weak or missing.

Process

The capstone moved from a general Q&A prototype to a source-only RAG workflow. The key design change was requiring retrieval and citation before final answer generation.

RAG Architecture Evidence first, answer second
1. AskPlain-English policy question
2. RetrieveSearch handbook chunks and section metadata
3. GroundAttach source excerpts and version
4. GenerateDraft concise answer from evidence
5. CiteShow section and confidence
6. EscalateRoute unclear or risky cases

Value Proposition

This project shows how generative AI can be applied responsibly in a high-stakes knowledge environment. The value is not only faster answers. The stronger value is consistency, citation traceability, and safer policy support. Faculty users receive a response they can verify, while uncertain cases are escalated instead of guessed.

Value thesis: A grounded handbook chatbot can reduce search friction while improving consistency, transparency, and accountability for routine faculty policy lookup.

The reflection emphasized stewardship: a responsible AI system should be useful, but also limited, accountable, and maintained. In this capstone, citation traceability and escalation logic are the main controls that move the assistant from a simple demo toward a tool that could be responsibly tested.
