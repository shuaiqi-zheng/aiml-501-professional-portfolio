Artifact 5 — Transfer Learning with Google Teachable Machine

A concise portfolio case study showing three browser-trained transfer-learning models: image, audio, and pose classification.

Introduction

This activity used Google Teachable Machine to prototype AI models with small labeled datasets. The portfolio value is not only that the models worked, but that the team compared validation results, identified model risk, and chose the safest model to ship.

Description

This artifact documents a hands-on transfer learning activity using Google Teachable Machine. The project built and tested three supervised classification models across different input types: an image model for animal recognition, an audio model for instrument/sound classification, and a pose model for body-position recognition. Each model was trained with labeled examples, tested with new inputs, and evaluated for accuracy, generalization, and practical deployment risk.

The activity shows how transfer learning can make model development accessible without writing custom model code. It also highlights the limits of small training datasets: image classification performed most reliably, audio results depended on background noise, and pose recognition was sensitive to camera angle, body position, and subject variation.

Objective

The objective was to build three working transfer-learning models across image, audio, and pose inputs; evaluate model quality with unseen neighbor-team samples; and defend one model for a real customer using customer value, risk, and guardrail reasoning.

Process

1. Build

Created image, audio, and pose projects in Teachable Machine and labeled each class with the required sample counts.

2. Test

Previewed each model and ran cross-team validation with samples not used during training.

3. Improve

Logged next steps: more lighting and angle diversity for images, cleaner/noisier audio samples, and more subjects for pose.

4. Ship

Selected the image model for a beginner animal-learning app because it was reliable, easy to explain, and lower risk than audio or pose.

Model Evidence

Image model: animal classes plus a “Not Any of the Above Animal” class.

Audio model: instrument classes tested against required background noise.

Pose model: hand and arm gesture classes trained with pose samples.

Validation finding: The pose model was useful but less production-ready. During neighbor testing, right-hand poses were misclassified, showing that camera angle and subject position can change model behavior.

Tools & Technologies

Google Teachable Machine

Browser-based tool used to train image, audio, and pose models.

Transfer Learning

Used pretrained model capabilities and small class-specific samples to create working prototypes quickly.

Cross-Team Validation

Used neighbor-team inputs to test generalization beyond the training examples.

Model Risk Guardrails

Applied a confidence-threshold guardrail to avoid forcing uncertain predictions.

Value Proposition

This artifact shows practical AI/ML judgment: building models is only the first step; a deployable model also needs validation evidence, error analysis, user fit, and guardrails. The image model offered the best balance of accuracy, explainability, and customer value.

Ship decision: Ship the image model for a beginner animal-learning app. Risk: low-quality or unusual images may be misclassified. Guardrail: if confidence is below 80%, show “Not sure — please retake or upload a clearer image.”

Improvement Plan

Image

Add more real-world images with different lighting, angles, blurry inputs, and non-animal examples.

Audio

Add more 2-second clips in both quiet and noisy settings to improve background-noise separation.

Pose

Add samples from more people, camera distances, standing positions, and body angles.
